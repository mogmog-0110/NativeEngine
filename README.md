# NativeEngine

周期境界を扱える剛体物理エンジン。C++17、外部依存なし（MSVC でビルド）。

PhysX、Bullet、Jolt、ODE などのゲーム向け物理エンジンは硬い接触を解けるが、領域の端が反対側につながる周期境界は表現できない。剛体が保持する姿勢と AABB はそれぞれ 1 つで、拘束に「どの格子像と接触しているか」を記録する場所がないためだ。分子動力学や DEM のコードは周期境界を扱える一方、接触をポテンシャルに緩めて解く。

NativeEngine はゲーム向けの逐次インパルス法を使い、トーラス構造を距離関数（minimum image）に組み込む。ゴースト剛体は作らない。端をまたぐ接触も、単一の剛体対として解決する。

周期境界を無効にすれば、通常のゲーム物理としても利用できる。他のリポジトリには依存しない。単体で完結する。

## 機能

- 球、箱、円柱、カプセル、凸包、平面、複合形状
- 静的三角形メッシュとハイトフィールド。BVH ミッドフェーズに対応
- 動的、静的、キネマティック剛体
- 摩擦、反発、combine mode を持つ材質
- 減衰、重力スケール、レイヤとマスク、`userData`
- 島単位のスリープと CCD
- 法線とクーロン摩擦を扱う逐次インパルスソルバ
- ウォームスタートと反発の slop
- 箱同士のクリッピングによる多点マニフォールド。平置きと積み上げを安定して処理
- 周期境界、反射壁、開いた地面
- 距離拘束（剛体ロッド、ばねダンパ）、ボール、ヒンジ、固定、スライダ
- 拘束の可動域制限、モータ、破断
- レイキャスト、オーバーラップ、スフィアキャスト。周期境界とレイヤを考慮
- トリガの `enter`、`stay`、`exit`
- 接触イベントの `begin`、`stay`、`end`
- キネマティックカプセルのキャラクタコントローラ。collide-and-slide、接地判定、斜面に対応
- デバッグ描画フックと描画補間
- 状態のスナップショット保存と復元
- 力、トルク、撃力の API
- ハンドルベースのファサード

## 検証

```text
build\NativeEngine.exe --selftest        # 169 / 169
```

周期境界では、並進不変性と、端をまたぐ衝突が自由空間での衝突に一致することを検証している。運動量とエネルギーの保存も対象で、いずれも機械精度で一致する。検証数は 169 件。

同じビルドへ同じ入力を与えた場合、結果はビット単位で一致する。これは評価順を固定した結果であり、シングルスレッド化や安定ソートで後から整合させたものではない。

ブロードフェーズには、周期境界対応の一様格子を使う。結果は O(N²) の総当たりとビット単位で一致する。

## ビルド

```text
build.bat                                # コア + selftest
```

必要なのは Visual Studio 2022 のみ。外部 SDK は不要。

## 使い方

`PhysicsWorld` はハンドルベースで、剛体を整数の `BodyId` として扱う。

```cpp
#include "physics_world.hpp"

ne::PhysicsWorld w;
w.setGravity({0.0, -9.81, 0.0});
w.setTimestep(1.0 / 60.0);
w.setOpenBoundary(true);       // 壁のない通常領域（既定は反射壁の箱）
w.setRestitution(0.2);         // 既定材質は完全弾性・摩擦 0 のため、落下後も止まらない
w.setFriction(0.5);

w.makeStatic(w.addBox({0.0, -1.0, 0.0}, {}, {50.0, 1.0, 50.0}, 1.0));
ne::BodyId ball = w.addSphere({0.0, 10.0, 0.0}, 0.5, 1.0);

for (int i = 0; i < 600; ++i) w.step();
ne::V3 p = w.position(ball);   // 床の上で静止（y = 0.489）

w.setBox(25.0, true);          // 端が反対側につながる領域に切り替える
```

接触イベント、レイキャスト、拘束、キャラクタコントローラも同じファサードから操作できる。

## ビジュアルデバッガ

エンジンを実時間で動かしながら内部を確認できるビューア。録画再生ではない。

Dear ImGui の UI に、シーン階層、剛体ごとのインスペクタ、統計を表示する。統計には FPS、剛体数、接触数、運動エネルギーのプロットが含まれる。3D オーバーレイでは、速度ベクトル、接触点と法線、AABB、選択強調、周期境界のゴースト像を確認できる。

剛体はクリックで選択できる。姿勢や速度もその場で編集可能。

```text
viewer\build_viewer.bat
build\NativeViewer.exe 1      # 1 ピラミッド 2 壁+ボール 3 ドミノ 4 球の山
                              # 5 円柱の山 6 ロープ 7 弾性気体 8 周期気体 9 周期ペア
```

キーボードでは `1`〜`9` でシーンを切り替え、`n` で次のシーンへ進む。`r` はリセット、`d` は剛体の落下、`space` は一時停止、`,` と `.` は速度変更、`h` はカメラを戻す操作に対応する。左ドラッグで回転し、ホイールでズーム、クリックで剛体を選択する。

すべて UI からも操作できる。

ビルドには freeglut が必要。`FREEGLUT_ROOT` の既定値は `E:\dev\freeglut`。Dear ImGui は `viewer/third_party/imgui` に同梱しており、MIT ライセンスの全文は同ディレクトリの `LICENSE.txt` にある。

## 構成

```text
src/
  vmath.hpp        double の Vec3 / 四元数、姿勢の積分
  body.hpp         剛体と各形状のファクトリ、外接半径
  box.hpp          周期 / 反射の箱: minimum image と巻き戻し
  gjk.hpp epa.hpp  support 関数 + GJK 交差判定、EPA による貫通深さと接触点
  narrowphase.hpp  球-円柱の解析解
  manifold.hpp     箱-箱のクリッピングマニフォールド
  detect.hpp       ナローフェーズの振り分け
  contact.hpp      撃力の解決（法線 + 摩擦）、有効質量
  queries.hpp      レイキャスト / オーバーラップ / スフィアキャスト
  character.hpp    カプセルのキャラクタコントローラ
  mesh.hpp         三角形メッシュ / ハイトフィールドと BVH
  world.hpp/.cpp   積分、ソルバ、拘束、ブロードフェーズ、スリープ、境界
  physics_world.hpp/.cpp   ハンドルベースのファサードと接触イベント
  selftest.cpp     物理のユニットテスト
viewer/            ImGui のビジュアルデバッガ（OpenGL 3.3）
mitiru/            ホストエンジンへ組み込むためのバインディング（sgc 型）
```

## 現状の制約

- レイキャストが対象とする形状は、球、箱、円柱、カプセルのみ。メッシュ、凸包、平面には未対応
- 多点マニフォールドは箱同士のみ。それ以外は単点接触をウォームスタートで安定化
- 凸包と複合形状の慣性テンソルは、頂点 AABB と平行軸の対角化による近似。極端に非対称な剛体では実物と差が出る
- ソルバはシングルスレッド。決定性を既定としているため
